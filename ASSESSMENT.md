## Evaluation Principles

### Technical correctness

- Definitions and explanations must be technically correct.
- PLC inputs, outputs and working stages must be properly identified.
- SCADA functions and the PLC–HMI–SCADA relationship must be clearly understood.

### Application and reasoning

- Examples should be relevant to automation.
- The water-tank scenario should demonstrate practical reasoning.
- Students should distinguish monitoring from automatic control.

### Documentation quality

- Answers should be clear, concise and written in the student’s own words.
- Tables and required fields should be complete.
- File names and repository structure should remain unchanged.

### GitHub practice

- The student should make at least three meaningful commits.
- Commit messages should describe the work completed.
- The automated structure check should pass.
- The submitted repository link should be accessible to the instructor.

### Reflection

- Reflection responses should be specific and genuine.
- The student should identify both learning progress and remaining questions.
