## 🎯 Purpose of This Assignment

This assignment revises the concepts covered in **Session 1: Introduction to PLC & SCADA**. It checks whether you can explain an automation system in your own words—not merely reproduce definitions.

After completing it, you should be able to:

- Explain why industrial automation is required
- Describe a PLC and its basic working cycle
- Distinguish between inputs, logic processing and outputs
- Explain the purpose of SCADA
- Relate PLC, HMI and SCADA to one another
- Apply these ideas to a simple industrial situation
- Submit neatly documented technical work using GitHub

The questions are aligned with the **PLC & SCADA Practical Workbook – Part 1** and the introductory classroom presentation.
